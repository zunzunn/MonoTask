# MotAnos

MotAnos is an AI-assisted productivity app focused on helping people with executive dysfunction finish the next task without overwhelm. It emphasizes a subtractive UI, gentle task decomposition, and tactile rewards that feel calm and satisfying rather than gamified.

## Summary
- **Purpose:** Reduce cognitive load by turning large tasks into 2-minute micro-wins.
- **Positioning:** Quiet, high-end "Zen-Tech" productivity for neurodivergent users.
- **Business model:** $4.99/mo subscription, with early-stage lifetime deal for founding members.

## Core Product Ideas
- **Decomposition Engine:** AI breaks a single user task into sequential 2-minute steps.
- **Potato Energy Mode:** Low-energy mode that simplifies tasks and softens UI tone.
- **Dopamine Engine:** Tactile rewards (task "pop," Zen Jar, and a long-term garden).
- **Subtractive UI:** Hide everything but the current task to enable tunnel vision focus.

## Differentiation vs Competitors
- **Instant start** vs planning-heavy tools like Sunsama.
- **Gentle control** vs auto-scheduling tools like Motion.
- **Ecosystem of rewards** vs simple step lists like Goblin.tools.
- **Professional, calm aesthetic** vs kid-like visuals in some ADHD apps.

## Landing Page Structure
1. **Hero:** "Productivity is too loud. MotAnos is the silence."
2. **Problem:** Starting is the real barrier; MotAnos hides the noise.
3. **Features:** Decomposition, Potato Energy, tactile rewards.
4. **Pricing:** $4.99/mo, framed as a "one coffee" purchase.
5. **Mission:** Built for neurodivergent users with empathy and clarity.

## Marketing & Distribution
- **Reddit:** Story-driven posts in ADHD and productivity communities.
- **Short video:** Zen Jar and task pop visuals for TikTok/Reels.
- **Product Hunt:** Launch with the Linen aesthetic.
- **Referral loop:** Free month for referrals.
- **Lead magnet:** "ADHD Tax" calculator on landing page.

## Roadmap (4 Weeks)
- **Week 1:** UI foundation, tokens, typography, core layout.
- **Week 2:** AI decomposition, streaming UI, pop interaction.
- **Week 3:** Potato Energy, Zen Jar, garden progression, Supabase.
- **Week 4:** Stripe billing, landing page, domain, beta testing.

## System Prompt (AI Behavior)
- Output JSON array of short steps only.
- 2-minute rule for every step.
- Start with the easiest action to build momentum.
- Use simple, encouraging language; avoid jargon.

## Design & Tech Stack
- **Design:** Quiet Luxury palette (Linen, Charcoal, Sage), Instrument Sans + Inter.
- **Framework:** Next.js 15 (App Router).
- **Data/Auth:** Supabase.
- **AI:** NVIDIA NIM (Llama 3) via OpenAI-compatible API.
- **Payments:** Stripe Checkout.
- **Motion:** GSAP + Lottie.
