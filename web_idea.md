# MonoTask: Web Design & Architecture Spec

## 1. Design Philosophy: "Zen-Tech"
MonoTask is not a tool; it is a **sanctuary**. The design must move away from the "busy" look of modern SaaS. It uses **Subtractive UI**—hiding everything that isn't the current priority.

### Visual Identity
- **Color Palette:** "Quiet Luxury"
  - Background: `#F9F7F2` (Warm Linen)
  - Text: `#1F1D1B` (Deep Charcoal - not pure black)
  - Accents: `#7C8C7F` (Sage Green) or `#D9A273` (Soft Terracotta)
- **Typography:**
  - Headers: *Instrument Sans* (Bold, Editorial feel)
  - Body: *Inter* or *Atkinson Hyperlegible* (High readability)

---

## 2. Page Architectures

### A. The "Morphing" Landing Page
- **The Initial State:** A single, large input field in the center of a blank linen screen. "What's the one thing you're avoiding?"
- **The Interaction:** As the user types, the page **GSAP-morphs** into the workspace. The background dims, and the text they typed becomes the "Hero Task."
- **Goal:** Conversion through immediate utility. No "Sign Up" wall until they see the AI break down their task.

### B. The "Tunnel Vision" Workspace
- **Bento-Grid Layout:** Soft-cornered cards (`border-radius: 24px`).
- **The Mono-Card:** A central, elevated card containing the active task. 
- **The "Path":** A vertical or horizontal string of smaller "pearls" representing sub-tasks generated by AI.
- **Glassmorphism:** Use `backdrop-filter: blur(10px)` for the "Potato Energy" mode toggle and settings.

---

## 3. Animation & Interaction Spec (GSAP & Lottie)

| Element | Interaction | Tech |
| :--- | :--- | :--- |
| **Task Entry** | Text expands and the "Path" grow out from underneath like a vine. | GSAP DrawSVG |
| **Sub-task Pop** | When clicked, the pearl "pops" with a burst of particles. | Lottie + Howler.js |
| **Energy Toggle** | The entire site's color temperature shifts from cool to warm. | GSAP ColorProps |
| **Loading** | A Lottie animation of a hand-drawn pencil sketching a path. | Lottie (JSON) |

---

## 4. Technical Stack Recommendation
- **Framework:** Next.js 15 (App Router).
- **Styling:** Vanilla CSS or Tailwind (with custom config for the Linen palette).
- **Physics:** GSAP for high-performance layout shifts.
- **AI Integration:** OpenAI GPT-4o-mini via Vercel AI SDK for streaming sub-task generation.
